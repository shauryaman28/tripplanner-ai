# The exact versions the test suites run on — and therefore the versions that are deployed (Phase 27).
#
# requirements.txt says what the app needs, with lower bounds. Installed on its own it takes the
# newest of everything, and the image that was deployed first ran SQLAlchemy 2.1 and sqlmodel 0.0.48
# where every test had run on 2.0 and 0.0.39: the first request that wrote a row answered 500.
# So the image and CI install with this file as a constraint:
#
#     pip install -r requirements.txt -c constraints.txt
#
# and get, of whatever requirements.txt asks for, exactly what was tested. A package named here that
# nothing asks for is not installed.
#
# To move to newer versions: upgrade the environment, run the three suites (unit + contract,
# integration, browser), and write the file again:
#
#     python scripts/freeze_constraints.py
#
